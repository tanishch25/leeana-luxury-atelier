# Codrops Rain Effect Master Guide

Based on Lucas Bebber's groundbreaking Codrops experiments, this skill provides the architecture for rendering realistic rain-on-glass, water droplet physics, and screen-space optical refraction in WebGL.

---

## 1. Technical Pipeline & Architecture

```
 ┌────────────────────────┐
 │ Droplet Physics Engine │ ── Generates drops, trails, gravity, and merging
 └───────────┬────────────┘
             │
             ▼
 ┌────────────────────────┐
 │  Normal Map Texture    │ ── Encodes droplet surface curvature into RGB (X, Y, Z normals)
 └───────────┬────────────┘
             │
             ▼
 ┌────────────────────────┐
 │ WebGL Post-Processing  │ ── Fragment shader displaces background image/video UVs
 └────────────────────────┘    via normal map + calculates chromatic refraction & highlights
```

## 2. Core GLSL Refraction & Highlight Shader

The secret to photorealistic glass drops is using the droplet normal to refract the background texture and adding specular lighting:

```glsl
precision mediump float;

uniform sampler2D uBg;           // Background image / scene texture
uniform sampler2D uWater;        // Normal map generated by droplet simulation
uniform vec2 uResolution;
uniform vec2 uTextureRatio;

varying vec2 vUv;

void main() {
  vec4 waterData = texture2D(uWater, vUv);
  
  // Extract surface normal from red & green channels (-1.0 to 1.0)
  vec2 normal = (waterData.rg - 0.5) * 2.0;
  float dropAlpha = waterData.a;
  
  // Refraction offset based on droplet curvature
  float refractionStrength = 0.04;
  vec2 distortedUv = vUv + normal * refractionStrength;
  
  // Chromatic dispersion (separating R and B channels slightly)
  float r = texture2D(uBg, distortedUv + normal * 0.003).r;
  float g = texture2D(uBg, distortedUv).g;
  float b = texture2D(uBg, distortedUv - normal * 0.003).b;
  
  vec3 refractedColor = vec3(r, g, b);
  
  // Specular light glint (sun / lamp reflection on top of droplet)
  vec3 lightDir = normalize(vec3(0.5, 0.8, 1.0));
  vec3 surfaceNormal = normalize(vec3(normal, sqrt(max(0.0, 1.0 - dot(normal, normal)))));
  float specular = pow(max(dot(surfaceNormal, lightDir), 0.0), 32.0) * 0.8;
  
  vec3 finalColor = refractedColor + vec3(specular * dropAlpha);
  gl_FragColor = vec4(finalColor, 1.0);
}
```

## 3. High-Performance Integration Tips

1. **Offscreen Canvas Texture**: Render the droplets onto an offscreen 2D canvas with standard circles/gradients, then upload as a `THREE.CanvasTexture` with `needsUpdate = true`.
2. **Resolution Downscaling**: Droplet physics do not need to run at native 4K. Render physics at half resolution (`scale = 0.5`), and let the WebGL shader's linear filtering smoothly interpolate the normals.
3. **Interactive Cursor Ripples**: When the user drags or moves their pointer across the screen, spawn a line of tiny droplets along the mouse trail to create an authentic tactile tactile interaction.
